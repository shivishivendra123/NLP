# 📝 Natural Language Processing (NLP) Practice  

🚀 This repository contains **NLP practice implementations**, covering **text preprocessing, word embeddings, POS tagging, and sentiment classification** using **FastText, Word2Vec, and GloVe**. It also includes **analysis of Game of Thrones books** and IMDB movie reviews.  

---

## 📂 Repository Structure  

### 🔹 1️⃣ Text Preprocessing  
- **Text Cleaning & Tokenization** (`Text_preprocessing.ipynb`)  
- **IMDB Dataset Preprocessing** (`IMDB Dataset 2.csv`)  

---

### 🔹 2️⃣ Word Embeddings & Feature Representations  
- **Word2Vec Implementation** (`Word2vec.ipynb`)  
- **IMDB Classification with Word2Vec** (`Word2vec_imdb.ipynb`)  
- **GloVe & FastText Embeddings** (`Glove_and_Fasttext.ipynb`)  
- **FastText Implementation** (`fasttext.ipynb`)  

---

### 🔹 3️⃣ Part-of-Speech (POS) Tagging  
- **POS Tagging Implementation** (`POS_tagging.ipynb`)  

---

### 🔹 4️⃣ NLP Applications & Projects  
- **IMDB Movie Reviews Classification**  
  - **Using Word2Vec, GloVe, and FastText**  
  - **File:** `Glove_and_Fasttext.ipynb`, `Word2vec_imdb.ipynb`  
- **Game of Thrones Books Analysis** (`gameOfThrones.ipynb`)
